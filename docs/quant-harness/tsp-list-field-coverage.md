Coverage uses TSP revision `f9cb383c5918c6a88a412f3ce43d59fe81b94ccc`. WhyJ delivery status refers to `main` at `6acad959379b8b9195d14d97d9c670c380fd1185` and staged implementations through #554, tree `546d802907af76c0c59106b9eb382fd5df194dbf`. `Merged` describes code present at that baseline. `Candidate` identifies work awaiting full delivery. Availability depends on the archive, asset, provider capability and evaluation time.

## How to read the fields

- `W/S` records the pinned watchlist and screener defaults. `shown` means visible by default, `hidden` means declared with visibility off, and `—` means absent from that panel's built-in declarations. These are 64 distinct keys across 114 declarations. [Column catalog](./tsp-list-catalog.md)
- Watchlist binds the saved membership to `/api/watchlist/enriched`. The response projects existing enriched columns, joins names and circulating shares, then appends displayed limits and return since addition. A financial column declaration can exist without a value supplied by this projection. [Enriched projection](https://github.com/shy3130/tick-stock-panel/blob/f9cb383c5918c6a88a412f3ce43d59fe81b94ccc/backend/app/api/watchlist.py#L393) · [Watchlist joins](https://github.com/shy3130/tick-stock-panel/blob/f9cb383c5918c6a88a412f3ce43d59fe81b94ccc/backend/app/api/watchlist.py#L587)
- The screener keeps the calculation-time scores, indicators and signals. Its display layer can use a newer quote for OHLC, volume, amount, change and turnover. Those fields carry quote time independently of strategy evaluation time. [Quote overlay](https://github.com/shy3130/tick-stock-panel/blob/f9cb383c5918c6a88a412f3ce43d59fe81b94ccc/backend/app/api/screener.py#L297) · [Score calculation](https://github.com/shy3130/tick-stock-panel/blob/f9cb383c5918c6a88a412f3ce43d59fe81b94ccc/backend/app/strategy/engine.py#L1927)
- The owning components render strategy tags, scores, signals and chart series. Daily and minute sparklines consume their separate batch endpoints. For the shared cases, the table identifies the value operand and omits styling-only operands such as `macd_hist` in the DIF cell. [Shared renderer](https://github.com/shy3130/tick-stock-panel/blob/f9cb383c5918c6a88a412f3ce43d59fe81b94ccc/frontend/src/components/stock-table/primitives.tsx) · [Screener table](https://github.com/shy3130/tick-stock-panel/blob/f9cb383c5918c6a88a412f3ce43d59fe81b94ccc/frontend/src/components/screener/ScreenerTable.tsx#L333) · [Chart API](https://github.com/shy3130/tick-stock-panel/blob/f9cb383c5918c6a88a412f3ce43d59fe81b94ccc/frontend/src/lib/api.ts#L3404)

## Remaining coverage

- Report archive, disclosure eligibility and value semantics are tracked separately. Tushare publishes basic EPS as `fina_indicator.eps`. The WhyJ archive extension and Source hookup are tracked in #560 and #561. The TSP factor catalog has report-based inputs, which provide separate evidence from list enrichment. [Tushare financial schema](https://tushare.pro/document/2?doc_id=79) · [TSP report factor mapping](https://github.com/shy3130/tick-stock-panel/blob/f9cb383c5918c6a88a412f3ce43d59fe81b94ccc/backend/app/backtest/fundamentals.py#L26) · [WhyJ financial replay](../agent-runtime/services.md#财务数据的历史时点)
- Current-day quote timestamps, adjusted historical indicators and selected-source entitlements affect which list cells are available. Dated observations and calculations can be reproduced with fixed archives. Live entitlement and list UI wiring require their own acceptance.
